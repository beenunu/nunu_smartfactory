🐍 파이썬 코드로 연결하기

📄
아래 코드는 이 파일 기준이에요

방금 본 표와 그래프, 파이썬으로도 똑같이 만들 수 있어요!
코드를 단계별로 같이 봐봐요 😊

①
라이브러리 불러오기 도구 상자를 꺼내는 단계예요
②
CSV 파일 열기 엑셀 파일을 파이썬에서 읽는 단계예요
③
데이터 저장 필요한 컬럼을 리스트에 담아요

그래프 출력 matplotlib으로 그래프를 그려요
📦 STEP 1 — 라이브러리 불러오기
step_1_import.py
import csv # CSV 파일 읽기 import matplotlib.pyplot as plt # 그래프 그리기
💡 as plt 가 뭐예요?
matplotlib.pyplot 을 매번 쓰기 길어서, 짧게 plt 라는 별명을 붙인 거예요!
📂 STEP 2 — CSV 파일 열기
step_2_open.py
f = open("2022_12_08_T11.csv", "r") rows = csv.reader(f) next(rows) # 첫 번째 줄(0,1,2... 숫자 헤더) 건너뛰기 next(rows) # 두 번째 줄(컬럼명 행) 건너뛰기
📌 next(rows) 를 두 번 쓰는 이유?
이 CSV 파일은 헤더가 2줄이에요!
첫 줄: 0, 1, 2, 3 ... 숫자 헤더
둘째 줄: x, y, z, xx ... 컬럼 이름
둘 다 데이터가 아니니까 next() 를 두 번 써서 건너뛰는 거예요!
🗂️ STEP 3 — 리스트에 데이터 저장
step_3_extract.py
x = [] # 시간(time_index) 저장 y = [] # y movement 데이터 z = [] # z movement 데이터 xx = [] # xx movement 데이터 for row in rows: x.append(int(row[0])) # 첫 번째 열 → 시간(x) y.append(float(row[9])) # 10번째 열 → y movement z.append(float(row[10])) # 11번째 열 → z movement xx.append(float(row[11])) # 12번째 열 → xx movement
💡 int vs float?
int() = 정수 변환 (1, 2, 3…)   float() = 소수 변환 (2.3, 3.14…)
시간은 정수, 센서값은 소수가 많아서 각각 다르게 변환해요!

💡 enumerate 안 써도 되나요?
next()로 헤더 2줄을 미리 건너뛰었기 때문에
이제 rows 에는 순수 데이터만 남아있어요.
그래서 for row in rows: 로 바로 읽으면 돼요! 😊
🔁 for문이 어떻게 동작하나요?

for row in rows: 는
CSV 파일을 한 줄씩 꺼내서 row 라는 이름으로 처리해요!

📄 rows (CSV 데이터)
skip 0, 1, 2, 3 ... 39 숫자 헤더 → next(rows)
skip x, hh:mm:ss, y, z, xx ... 컬럼명 → next(rows)
1회차 1, 10:15:41, ..., -106.674, 160.995, 269.577 ... → row 변수에 담김
2회차 2, 10:15:41, ..., -106.674, 160.995, 269.577 ... → row 변수에 담김
3회차 3, 10:15:41, ..., -72.025, 98.595, 269.577 ... → row 변수에 담김
... 총 757행 반복
row =
한 줄씩
▶
⚙️ 한 줄(row) 처리
[0] 1 → x 리스트에 추가
[9] -106.674 → y 리스트에 추가
[10] 160.995 → z 리스트에 추가
[11] 269.577 → xx 리스트에 추가
현재: 1회차
📦 리스트에 쌓이는 데이터
x [ 1 ]
y [ -106.674 ]
z [ 160.995 ]
xx [ 269.577 ]

※ 실제 데이터 기준 (2022_12_08_T11.csv 1~3행)

📊 STEP 4 — 그래프 그리기
step_4_plot.py
# 📈 그래프 선 그리기 plt.plot(x, y, label='y movement') plt.plot(z, label='z movement') plt.plot(xx, label='xx movement') # 🏷️ 레이블 설정 plt.xlabel('Number of times') plt.ylabel('movement') plt.title('Movement of x,y,z') plt.legend() # 범례 표시 plt.show() f.close()
📌 legend() 가 뭐예요?
어느 선이 y, z인지 알려주는 범례(설명 박스)예요!
label에 적어준 이름이 여기서 보여요 🏷️
